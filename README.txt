ASTHA & LAVI PRINTING PRESS WEBSITE
==================================

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open the website in your browser.

FOLDER STRUCTURE
- index.html       Home page
- about.html       About the press and team
- services.html    Printing services
- gallery.html     Sample image gallery
- offers.html      Promotional ad designs
- order.html       WhatsApp order form
- contact.html     Contact and address
- admin.html       Basic local admin demo
- css/style.css    Shared website styling
- js/main.js       Shared menu and footer behavior
- js/order.js      WhatsApp order form
- js/admin.js      Local announcement demo

IMPORTANT
- Internet is required for remote sample photos and Google Fonts.
- Gallery photos are sample/illustrative images. Replace them with your actual work photos.
- Offers page contains promotional ad copy, not confirmed discounts or prices.
- Admin page is only a local browser demo. It is not password protected and does not store customer orders on a server.
- WhatsApp order form opens WhatsApp with a pre-filled message. The customer must press Send.
- For a real multi-user admin dashboard, order database, secure login and upload system, connect a backend (for example Firebase or a custom server).
